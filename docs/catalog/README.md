# About This Catalog

This directory is the human-facing layer of dsh-bridge's trust system: a short list of DeepSeek Harness plugins we have actually audited, each with a grade and a link to the full evidence. [INDEX.md](INDEX.md) is the entry point, one row per plugin with the grade, a one-line verdict, and the verification date. The complete write-ups live in [cards/](cards/), where every claim carries file-and-line citations back to the audited source.

Cards are produced by the dsh-bridge trust pipeline described in [docs/trust/pipeline-architecture.md](../trust/pipeline-architecture.md). A review pins an exact commit, runs a static scanner against a versioned heuristics corpus, then applies manual adversarial source review on top. Every scanner finding is adjudicated in the open: false positives are traced to their cause, real capabilities are kept and graded rather than hidden, and the raw machine grade is published next to the final one even when they disagree. A grade is an opinion over one pinned revision with reproducible inputs; it is not a safety guarantee, and every card says so.

This is not an awesome list. Awesome lists aggregate by discovery and taste: entries arrive via pull request, popularity is the ranking signal, and nothing verifies the code behind the link. This catalog inverts those choices: inclusion requires a completed audit against a pinned commit, ordering follows evidence-based grades rather than stars, and every row links to a card whose claims you can re-run yourself with the commands at the bottom of each card. Popularity appears only as context, never as a proxy for safety.
