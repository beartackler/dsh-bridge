Verified plugin catalog for DeepSeek Harness

DeepSeek Harness plugins you can verify before you install.

dsh-bridge is a DeepSeek Harness plugin for people arriving from Claude Code, Codex CLI, OpenCode, or Jcode: familiar slash commands, guided provider setup, and a curated plugin catalog. Every community plugin in that catalog passes an adversarial security review against a pinned commit before we recommend it, and each verdict ships as a trust report card citing file-and-line evidence you can re-run yourself.

About these grades

AGrade A:
Verified-clean. No high or critical findings; recommended by default in /bridge:install.
BGrade B:
Safe with documented behavior. Any egress is documented and user-visible.
CGrade C:
Use with awareness. Real capabilities or gaps to know about first. Also the ceiling when the pipeline could not fully examine a plugin.
DGrade D:
Risky. Undocumented egress, obfuscation signals, or a disputed high finding. Install only if you understand the named risk.
FGrade F:
Do not install. Demonstrated hostility.

A grade is an evidence-backed opinion over one pinned commit as of its verified date. It is not a safety guarantee and says nothing about any other version. How grading works (docs/trust/pipeline-architecture.md) covers the full pipeline: scanner rules, behavioral probes, cross-model review, and the evidence standard behind each band.
